# BiblioSoftware - Soluzione Integrata per la Gestione delle Biblioteche

Un'applicazione Python semplice e intuitiva per la gestione dell'inventario di una biblioteca.

## 💡 Descrizione
**BiblioSoftware** permette di gestire l'inventario dei libri, monitorare la disponibilità delle copie, registrare i prestiti, restaurare i volumi e visualizzare le statistiche generali del sistema tramite un menu interattivo.
