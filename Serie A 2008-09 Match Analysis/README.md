# Serie A 2008-09 Match Analysis
 
Uno script Python semplice per l'analisi dei risultati della Serie A 2008-09: punti, vittorie/pareggi/sconfitte e classifica finale.
 
## 💡 Descrizione
 
Lo script analizza il dataset precaricato con tutte le partite della stagione 2008-09 (`li`), calcola il totale punti e il numero di vittorie/pareggi/sconfitte per una squadra scelta dall'utente, e genera la classifica completa del campionato tramite un dizionario `{squadra: punti}`.
